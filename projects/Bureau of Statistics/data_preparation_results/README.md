# Prepared survey data

Generated by [Assignment_Solution.ipynb](../Assignment_Solution.ipynb) after the field-by-field investigation and preparation decisions. This stage stops at numerical inputs. No occupation classifier has been trained and no occupation code has been predicted.

The original survey contains 200 identified records. The complete-target subset has 191 records across 59 classes. Nine records retain incomplete targets containing `X` and are kept separately. The primary matrices contain 6,506 features, learned from the complete-target subset only.

| File | Contents |
| --- | --- |
| `prepared_survey.csv` | All 200 prepared records, including retained dates, industry codes, and recorded targets |
| `preparation_audit.csv` | Response states, reference resolution, observed contradictions, and future validation groups |
| `training_inputs.csv` | Prepared predictors and complete recorded targets, with IDs in matrix row order |
| `prediction_inputs.csv` | Prepared predictors and incomplete recorded targets, with IDs in matrix row order |
| `training_features.npz` | Sparse numerical features for the 191 complete-target records |
| `prediction_features.npz` | Sparse numerical features for the nine incomplete-target records |
| `feature_names.csv` | Primary matrix columns in their encoded order |
| `industry_training_features.npz` | Separately encoded industry values for the complete-target records |
| `industry_prediction_features.npz` | Separately encoded industry values for the incomplete-target records |
| `industry_feature_names.csv` | Separate industry-matrix column names |
| `workplace_transformations.csv` | Original and transformed workplace values from the preceding LaBSE cell |
| `feature_encoders.joblib` | Fitted primary and industry encoders |
| `preparation_manifest.json` | Source checksum, feature selection, row IDs, package versions, and preparation scope |

Seven text fields use separate character TF-IDF vocabularies. Categories and text-response states use one-hot encoding. Age and schooling use training-set median imputation and standard scaling, with separate missing indicators. The primary matrix excludes ID, role-start date, industry code, and the occupation target. Industry remains separate because its availability before occupation prediction is not established. Dates remain dates because no survey reference date was supplied for calculating tenure.

The audit identifies nine salary-source eligibility contradictions, a manager/deputy disagreement, two qualification/schooling review cases, and four identical original predictor records carrying conflicting occupation labels. It also flags the existing workplace transformation for record 140, which changes an IT-consultancy description into a cosmetics-related description. The original workplace wording remains in `workplace_transformations.csv`. These flags record issues, not corrected facts.

Before cross-validation, clone and refit the complete encoder on each training fold. Do not validate on these matrices after fitting the encoder on all 191 records. Any evaluation of workplace matching must also construct its candidate vocabulary inside the training fold. The saved numerical matrices are inputs for a later final fit, not evidence of model performance.

Load sparse matrices with `scipy.sparse.load_npz`. Read occupation and industry codes as strings so that leading zeros and `X` characters survive CSV loading. The fitted encoder uses the package versions recorded in the manifest. The notebook is the reproducible source for regenerating all outputs.
