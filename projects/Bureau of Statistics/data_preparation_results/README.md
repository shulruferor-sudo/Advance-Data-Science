# Prepared survey data

Generated by [Assignment_Solution.ipynb](../Assignment_Solution.ipynb) after the field-by-field investigation and preparation decisions. This stage stops at numerical inputs. No occupation classifier has been trained and no occupation code has been predicted.

The original survey contains 200 identified records. The complete-target subset has 191 records across 59 classes. Nine records retain incomplete targets containing `X` and are kept separately. The primary matrices contain 687 numerical features. Vocabularies, category mappings, and imputation values are fitted on the complete-target records.

| File | Contents |
| --- | --- |
| `prepared_survey.csv` | All 200 records with numerical predictors, IDs, and recorded occupation targets |
| `preparation_audit.csv` | Nine recorded salary-source combinations that contradict questionnaire eligibility |
| `training_inputs.csv` | Prepared predictors and complete recorded targets, with IDs in matrix row order |
| `prediction_inputs.csv` | Prepared predictors and incomplete recorded targets, with IDs in matrix row order |

| `prediction_features.npz` | Sparse numerical features for the nine incomplete-target records |

| `preparation_manifest.json` | Row IDs, package versions, preparation rules, and tenure reference date |

Each text field is completed within its own notebook section, including its reasoned handling of blanks, non-disclosure, and references. Seven fields use separate word vocabularies with the same TF-IDF configuration, ordinary term counts, unsmoothed IDF, and no L2 normalization at this preparation stage. No missingness indicators or shared response-state features are added. Locality, employment status, salary source, and qualification use their specified one-hot encodings. Management uses the specified 0–3 level representation, with blanks encoded as zero. Schooling and age use their specified ranges and separately fitted median replacements.

`TarichHathala` contains years on the job in the prepared table. Elapsed days from the starting date to 6 November 2026 are divided by 365.25. Under the immediate-processing interpretation, the current execution date substitutes for the unavailable survey or last-update date. This assumption must also appear in the presentation. The source table retains the original dates. Industry remains separately encoded because its availability before occupation prediction is not established.

Before cross-validation, refit every learned transformation within each training fold, including the workplace matching candidates. The saved matrices are prepared for fitting on all 191 complete labels and must not be reused as already-fitted inputs to validation. The later classifier comparison will select one common TF-IDF normalization setting and retain cluster features only if they improve the same validation comparison. No classifier or representation comparison has been run in this preparation stage.

Load sparse matrices with `scipy.sparse.load_npz`. Read occupation and industry codes as strings so that leading zeros and `X` characters survive CSV loading. The fitted encoder uses the package versions recorded in the manifest. The notebook is the reproducible source for regenerating all outputs.
