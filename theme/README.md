# Project themes

Choose the theme by the destination of the finished work.

| Theme | Where to use it | Entry points |
| --- | --- | --- |
| [Portfolio](portfolio/) | Presentations, interview assignments, notebooks, dashboards, reports, websites and other work outside an arXiv paper. | [Web stylesheet](portfolio/portfolio.css), [color tokens](portfolio/palette.json), [Plotly template](portfolio/plotly.json), [Matplotlib style](portfolio/portfolio.mplstyle) and [original artwork](portfolio/assets/) |
| [LaTeX for arXiv](arxiv-latex/) | Manuscripts prepared for arXiv and figures or tables embedded in those manuscripts. | [Manuscript starter](arxiv-latex/main.tex), [LaTeX style](arxiv-latex/orpaper.sty) and [figure style](arxiv-latex/paper.mplstyle) |

For a paper and a talk about the same work, typeset the manuscript with the LaTeX theme and design the talk with the portfolio theme. The same rule applies in every language. Choose fonts with the necessary glyph coverage while keeping the theme’s colors and layout.
