# abstract

this paper develops an approach to learn a policy of a dynamical system that is guaranteed to be both provably safe and goal-reaching. here, the safety means that a policy must not drive the state of the system to any unsafe region, while the goal-reaching requires the trajectory of the controlled system asymptotically converges to a goal region (a generalization of stability). we obtain the safe and goal-reaching policy by jointly learning two additional certificate functions: a barrier function that guarantees the safety and a developed lyapunov-like function to fulfill the goal-reaching requirement, both of which are represented by neural networks. we show the effectiveness of the method to learn both safe and goal-reaching policies on various systems, including pendulums, cart-poles, and uavs.

# 1 introduction

we summarize three levels of priorities in order for policy learning tasks:

safety: the motion of a system under a policy must not run into any unsafe region.

stability: the motion of a system under a policy is bounded around or attractive to a point.

optimality: the trajectory of a system under a policy maximizes an accumulative reward.

existing techniques extensively focus on learning a policy of optimality. these methods typically use the framework of reinforcement learning [1], which evaluates and improves the policy by interacting with environments/systems. although achieving notable progress [2-4], their deployments are still limited and a key challenge is the safety issue during the exploration process [5]. in practice, safety and stability always come first before the pursuit of policy optimality. although recent work [6-9] began to consider safety in the development of learning techniques, most of them use lyapunov theory [10] and achieve safety by requiring attractiveness, i.e., stability, of the system's behavior. such attractiveness requirement, although sufficient to guarantee safety, is typically conservative.

in this paper, we distinguish safety from stability: stability requires a policy to enable the system to have attractive or bounded behavior, while safety concerns that a policy must not drive the state of a system into any unsafe region. with this difference, we focus on learning a policy that is both safe and stable. as illustrated in fig. 1, first we guarantee that under the control policy, the trajectory of the system from an initial state set  $\mathcal{x}_0$  asymptotically converges to a specified goal state set  $\mathcal{x}_g$ . we here refer this property to as 'goal-reaching', which is a generalization of stability. second, the policy guarantees that the system, starting from any state in an initial state set  $\mathcal{x}_0$ , must not enter into any unsafe state set  $\mathcal{x}_u$ , which we refer to as safety. this paper develops an approach to learn a policy of both safety and goal-reaching. the key here is to jointly learn the policy together with two certificate functions, where we use a neural barrier function [11] to account for the safety and a neural lyapunov-like function to guarantee attractiveness of the system to a given goal set.

# 1.1 background and related work

lyapunov stability. the lyapunov theory [10] is a systematic methodology to characterize the stability of a dynamical system. given a valid lyapunov function, the motion of a dynamical system is guaranteed to be bounded (or attractive to, depending on specific conditions) around an equilibrium point. however, finding a valid lyapunov function is generally challenging. although some methods, e.g., sum-of-square [12] and learning from demonstrations [13], attempt to propose a general solution, but they are limited to simple systems, such as requiring polynomial dynamics or restricting lyapunov functions to be a weighted sum of features. in this paper, we develop a lyapunov-like function, which can be viewed as a generalization of the lyapunov theory, which provides a provable certificate for a controlled system to converge to a state set instead of an equilibrium point.

lyapunov based safe learning. due to the provable boundness by the lyapunov theory, a set of recent work [6-9] treats safe policy learning from the perspective of system stability. the core of these work is to jointly learn the policy and the lyapunov function, which ensures the behavior of the controlled system constrained within a region of attraction considered as a safe region. in most of cases, these methods will lead to a policy which is not only safe but also stable in a sense of driving the system converging to a fixed (equilibrium) point. such definition and treatment of safety is usually conservative, because a safe policy does not necessarily have to be stable.

conservativeness comparison between optimality, stability, and safety. we include the optimal policy resulting from reinforcement learning and compare the conservativeness between the concepts of optimality, stability, and safety of a policy. first, optimality of a policy generally implies stability, and this is because the value function for an optimal policy can be directly viewed as a valid lyapunov function since the bellman equation satisfies all conditions required for a valid lyapunov function (note that the opposite claim does not necessarily hold) [14]. second, definition of lyapunov stability states the boundness of system behavior at an equilibrium point [10], which can be understood as a more restrictive safety. thus, we can conclude that in terms of safety guarantee, optimality is more conservative than stability, and stability can be thought of as a more restrictive treatment of safety.

barrier functions for safe control. barrier functions [11, 15-17] were introduced to the control field to account for safety requirement in control design. by providing a barrier function and defining safe/unsafe sets as level-sets of the barrier function, trajectories of the system can be guaranteed to never cross the boundary of level sets. in the learning field, barrier functions are recently employed to guarantee safety in learning of a policy or dynamics, such as [18-20]. all these methods require a valid barrier function to be available.

learning barrier functions. whenever the unsafe/safe sets are not given in the algebraic form using a barrier function, one cannot leverage the safety guarantee that barrier functions provide. a very recent set of work has explored to learn barrier functions from data. in [21], barrier functions are parameterized by linear functions, and a method is developed to update the linear barrier functions incrementally. in [22], the authors use the support vector machine to learn a barrier function in a supervised way. these approaches however are restricted to the systems whose dynamics is affine in control inputs. in those cases, learning a barrier function is decoupled from finding a policy, and the learning process is reduced to solving a binary classification problem. since the policy is not considered in the process of learning barrier function, the obtained barrier function may be no longer valid when the policy is included. furthermore, the policy in these methods is usually solved using quadratic programming after the barrier function is learned; even though safety is guaranteed, stability of the policy might not be satisfied.

our contributions. first, instead of decoupling the process of learning a barrier function and obtaining a safe policy, we jointly learn them from data to guarantee that the barrier function is valid and the policy is safe; and thus our approach is able to apply to more general non-linear systems (such as non-affine systems). second, we develop a general lyapunov-like function and incorporate learning of such lyapunov-like function into the policy learning process. as a result, the learned policy is guaranteed to be not only safe but also goal-reaching in a sense of driving the system to converge to a goal set. here, the control policy, barrier function, and lyapunov-like function are all represented by neural networks. our results show that by jointly including these certificate functions (i.e., barrier and lyapunov-like functions) in learning, we can finally obtain a policy that is both safe and goal-reaching.

# 2 problem statement

notations. the set of non-negative real numbers are denoted by  $\mathbb{r}_0^+$ . the gradient of a differentiable scalar function  $v(\pmb{x})$  is denoted as  $\nabla v(\pmb{x})$ , i.e.,  $\nabla v(\pmb{x}) = \partial v / \partial \pmb{x}$ . the distance from  $\pmb{x}$  to a set  $\mathcal{s}$  is defined by  $\| \pmb{x} \|_{\mathcal{s}} = \inf_{\pmb{s} \in \mathcal{s}} \| \pmb{x} - \pmb{s} \|$  ( $\| \cdot \|$  is the euclidean norm). a continuous function  $\alpha : [0, a) \to [0, +\infty)$  for some  $a > 0$  is said to belong to class  $\mathcal{k}$  if it is strictly increasing and  $\alpha(0) = 0$ . a continuous function  $\beta : (-b, a) \to (-\infty, +\infty)$  for some  $a, b > 0$  is said to belong to extended-class  $\mathcal{k}$  if it is strictly increasing and  $\beta(0) = 0$ . a continuous function  $\gamma : [0, c) \times [0, \infty) \to [0, +\infty)$  for some  $c > 0$  is said to belong to class  $\mathcal{kl}$ , if for each fixed  $s$ , the mapping  $\gamma(r, s)$  belongs to class  $\mathcal{k}$  with respect to  $r$  and for each fixed  $r$ , the mapping  $\gamma(r, s)$  is decreasing with respect to  $s$  and  $\gamma(r, s) \to 0$  as  $s \to \infty$ .

we consider the a dynamical system:

$$
\dot {\boldsymbol {x}} = \boldsymbol {f} (\boldsymbol {x}, \boldsymbol {u}), \quad \boldsymbol {x} (0) = \boldsymbol {x} _ {0}, \tag {1}
$$

where  $\pmb{x} \in \mathcal{x} \subseteq \mathbb{r}^n$  is the system state with  $\mathcal{x}$  defining the system state space;  $\pmb{u} \in \mathcal{u} \subseteq \mathbb{r}^m$  is the control input with  $\mathcal{u}$  defining the control space; and the vector function  $\pmb{f}: \mathcal{x} \times \mathcal{u} \to \mathcal{x}$  is assumed to be continuously differentiable. for (1), we define a continuously differentiable policy

$$
\boldsymbol {u} = \boldsymbol {u} (\boldsymbol {x}), \tag {2}
$$

which defines a map from state to control,  $\pmb{u} : \mathcal{x} \rightarrow \mathcal{u}$ . equipped with the policy (2), the system (1) becomes a controlled (autonomous) system  $\dot{\pmb{x}} = \pmb{f}(\pmb{x}, \pmb{u}(\pmb{x}))$ , and we below write as  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  for simplicity. given an initial state  $x_0$ , the motion of the controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  is a trajectory denoted by  $\pmb{x}_{\pmb{u}}(t)$  for  $t \in \mathbb{r}_0^+$ , which is a state of time with  $\pmb{x}_{\pmb{u}}(0) = \pmb{x}_0$ .

the goal in this paper is to find a policy (2) such that the controlled system, starting from  $\mathbf{x}_0$ , will be guaranteed to (i) reach a given goal state and (ii) ensure safety. we specifically illustrate these two requirements using fig. 1. define a set of initial states  $\mathcal{x}_0 \subseteq \mathcal{x}$ , a set of unsafe states  $\mathcal{x}_u \subseteq \mathcal{x}$  with  $\mathcal{x}_u \cap \mathcal{x}_0 = \emptyset$ , and a set of goal states  $\mathcal{x}_g \subseteq \mathcal{x}$  with  $\mathcal{x}_u \cap \mathcal{x}_g = \emptyset$ . our goal is to find a policy  $\mathbf{u} = \mathbf{u}(\mathbf{x})$  such that from any  $\mathbf{x}_0 \in \mathcal{x}_0$ , the system's trajectory  $\mathbf{x}_u(t)$  with  $t \in \mathbb{r}_0^+$  will finally reach the goal set  $\mathcal{x}_g$  while avoiding entering into the unsafe set  $\mathcal{x}_u$ . more formally, we give the following definitions for the safety and goal reaching of a policy, respectively.

definition 2.1 (safety of a policy). for the system (1) with a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$  and a set of unsafe states  $\mathcal{x}_u\subseteq \mathcal{x}$ , we say a policy  $\pmb {u} = \pmb {u}(\pmb {x})$  is safe with respect to the unsafe set  $\mathcal{x}_u$ , if there does not exist a trajectory  $\pmb{x}_{\pmb{u}}(t)$  such that  $\pmb {x}(0)\in \mathcal{x}_0$  and  $\pmb {x}(t)\in \mathcal{x}_u$  for some  $t\in \mathbb{r}_0^+$ .

definition 2.2 (goal reaching of a policy). for the system (1) with a set of initial states  $\mathcal{x}_0 \subseteq \mathcal{x}$  and a set of goal states  $\mathcal{x}_g \subseteq \mathcal{x}$ , we say a policy  $\boldsymbol{u} = \boldsymbol{u}(\boldsymbol{x})$  is goal-reaching with respect to the goal set  $\mathcal{x}_g$ , if there exists a  $\mathcal{kl}$ -function  $\gamma$  such that for any  $\boldsymbol{x}(0) \in \mathcal{x}_0$ ,

$$
\left\| \boldsymbol {x} _ {\boldsymbol {u}} (t) \right\| _ {\mathcal {x} _ {g}} \leq \gamma \left(\left\| \boldsymbol {x} (0) \right\| _ {\mathcal {x} _ {g}}, t\right) \quad f o r a l l \quad t \in \mathbb {r} _ {0} ^ {+} \tag {3}
$$

the definition for safety in definition 2.1 states that a safe policy is the one that must not lead the system state, from initial state set  $\mathcal{x}_0$ , to the unsafe set  $\mathcal{x}_u$ . the definition of goal-reaching in definition 2.2 requires the policy always to drive the system state towards getting closer to the goal set  $\mathcal{x}_g$ . based on these two formal definitions, we present the problem of interest of this paper:

the problem of interest: given a system (1) with an initial state set  $\mathcal{x}_0\subseteq \mathcal{x}$ , an unsafe set  $\mathcal{x}_u\subseteq \mathcal{x}$  and a goal set  $\mathcal{x}_g\subseteq \mathcal{x}$ , we aim to find a policy (2) that is both safe and goal-achieving.

# 3 theoretical results

we analyze the problem of interest by decomposing it to safe policy design and goal-reaching policy design, each of which will be discussed below. for the safety policy design, we use barrier functions, which were introduced to control systems in [11, 15, 16]. for the goal-reaching policy design, we modify the lyapunov function [10, 23, 24] and develop a more general lyapunov-like function. we refer to both barrier and lyapunov-like functions as certificate functions.

first, we adapt the barrier function used in [15] to be the following:

definition 3.1 (barrier function [15]). consider a controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  with policy  $\pmb{u}:\mathcal{x}\rightarrow \mathcal{u}$  and  $\pmb{f}_{\pmb{u}}:\mathcal{x}\rightarrow \mathcal{x}$  both continuously differentiable, a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$ , and a set of unsafe states  $\mathcal{x}_u\subseteq \mathcal{x}$ . a continuously differentiable function  $b(\pmb {x}):x\to \mathbb{r}$  is called a control barrier function, if there exists an extended class- $\mathcal{k}$  function  $\beta$  such that

$$
b (\boldsymbol {x}) \leq 0 \quad \forall \boldsymbol {x} \in \mathcal {x} _ {0}, \tag {4a}
$$

$$
b (\boldsymbol {x}) > 0 \quad \forall \boldsymbol {x} \in \mathcal {x} _ {u}, \tag {4b}
$$

$$
\nabla b (\boldsymbol {x}) \boldsymbol {f} _ {\boldsymbol {u}} (\boldsymbol {x}) \leq - \beta (b (\boldsymbol {x})) \quad \forall \boldsymbol {x} \in \mathcal {x}. \tag {4c}
$$

compared to the barrier function defined in [11, 15] which requires  $\nabla b(\pmb{x})\pmb{f}_{\pmb{u}}(\pmb{x}) \leq 0$  for all  $\pmb{x} \in \mathcal{x}$ , we relax it in (4c). recall that  $\beta(\cdot)$  is an extended class- $\mathcal{k}$  function, which could take negative values for  $b(\pmb{x}) \leq 0$ . thus, we allow  $\nabla b(\pmb{x})\pmb{f}_{\pmb{u}}(\pmb{x}) > 0$  for  $b(\pmb{x}) < 0$ , which makes (4c) more likely be fulfilled. the interpretation of the above barrier function is straightforward: (4a) and (4b) state that the unsafe and initial sets can be separated by the barrier function; and (4c) guarantees that trajectory of the controlled system starting from  $\mathcal{x}_0$  can only stay within the set  $\{\pmb{x} : b(\pmb{x}) \leq 0\}$  and cannot go out and enter into the unsafe set. the rigorous assertion for this is stated in as follows.

lemma 3.1 (safe control theorem [16]). given the controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  with policy  $\pmb{u}:\mathcal{x}\rightarrow \mathcal{u}$  and  $\pmb {f_{u}}:\mathcal{x}\to \mathcal{x}$  both continuously differentiable, a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$ , and a set of unsafe states  $\mathcal{x}_u\subseteq \mathcal{x}$ , if  $b(\pmb {x})$  is a barrier function as in definition 3.1, then the policy  $\pmb {u} = \pmb {u}(\pmb {x})$  is safe with respect to  $\mathcal{x}_u$ , as defined in definition 2.1.

a proof of the above lemma can be found in [16] and also in appendix a. we here give an intuition behind theorem 3.1. if these exist a barrier function  $b(\pmb{x})$ , then any state  $\pmb{x}_{\pmb{u}}(t)$  along the trajectory of the controlled system, starting from  $\mathcal{x}_0$ , will have  $b(\pmb{x}_{\pmb{u}}(t)) \leq 0$  for all  $t \in \mathbb{r}_0^+$  and  $b(\pmb{x}_{\pmb{u}}(t))$  cannot become positive because the decreasing property (4c). this means that the state of the system will stay inside the set  $\{\pmb{x} : b(\pmb{x}) \leq 0\}$  cannot go out of it, thus of course is safe with respect to  $\mathcal{x}_u$ .

we next focus on find a certificate for the goal-reaching requirement in definition 2.2. to this end, we define the following lyapunov-like function.

definition 3.2 (lyapunov-like function). consider a controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  with policy  $\pmb{u}:\mathcal{x}\rightarrow \mathcal{u}$  and  $\pmb{f_{u}}:\mathcal{x}\to \mathcal{x}$  both continuously differentiable, a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$ , and a set of goal states  $\mathcal{x}_g\subseteq \mathcal{x}$ . a continuous differentiable function  $v(\pmb {x}):x\to \mathbb{r}$  is said to be a lyapunov-like function if

$$
\emptyset \neq \left\{\boldsymbol {x}: v (\boldsymbol {x}) \leq 0 \right\} \quad a n d \quad \left\{\boldsymbol {x}: v (\boldsymbol {x}) \leq 0 \right\} \subseteq \mathcal {x} _ {g}, \tag {5a}
$$

$$
\nabla v (\boldsymbol {x}) \boldsymbol {f} _ {\boldsymbol {u}} (\boldsymbol {x}) \leq - \beta (v (\boldsymbol {x})) \quad \forall \boldsymbol {x} \in \mathcal {x}, \tag {5b}
$$

for some extended class  $\kappa$  function  $\beta$ .

note that the above lyapunov-like function is more general than the classic lyapunov function used in [7-10], where it requires  $v(\pmb{x}) > 0$  for  $\pmb{x} \in \mathcal{x} \backslash 0$ ,  $v(0) = 0$ , and  $\nabla v(\pmb{x})\pmb{f}_{\pmb{u}}(\pmb{x}) < 0$ . first, the above lyapunov-like function allows for specifying a goal state set in addition to a fixed point. second, the lyapunov-like function do not necessarily require that  $\nabla v(\pmb{x})\pmb{f}_{\pmb{u}}(\pmb{x})$  has to be always negative-definite, that is,  $\nabla v(\pmb{x})\pmb{f}_{\pmb{u}}(\pmb{x}) > 0$  can happen for  $\pmb{x} \in \{\pmb{x}: v(\pmb{x}) < 0\}$ ; this will make the lyapunov function less restrictive. based on definition 3.2, we provide the following theorem, which states a certificate to guarantee the control policy is goal-reaching.

theorem 1 (goal-reaching control theorem). given the controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  with policy  $\pmb{u}:\mathcal{x}\rightarrow \mathcal{u}$  and  $\pmb {f}_u:\mathcal{x}\to \mathcal{x}$  continuously differentiable, a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$ , and a set of goal states  $\mathcal{x}_g\subseteq \mathcal{x}$ , if  $l(\pmb {x})$  is a barrier function as in definition 3.2, then the policy  $\pmb {u} = \pmb {u}(\pmb {x})$  is goal-reaching with respect to  $\mathcal{x}_g$ , as defined in definition 2.2.

a proof of the above theorem is given in appendix a. the assertion, however, is quite intuitive: the existence of  $v(\pmb{x})$  guarantees that the state along the system trajectory  $\pmb{x}_u(t)$  is decreasing the value of  $v(\pmb{x})$  (see (5b)), which implies that it is approaching  $\mathcal{x}_g$ , thus goal-reaching by definition 2.2.

combining theorems 3.1 and 1, we immediately obtain the following assertion stating that existence of barrier and lyapunov-like certificates guarantees the policy is both safe and goal-achieving.

theorem 2 (safe and goal-reaching control theorem). consider a controlled system  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  with policy  $\pmb{u}:\mathcal{x}\rightarrow \mathcal{u}$  and  $\pmb {f_u}:\mathcal{x}\rightarrow \mathcal{x}$  both continuously differentiable. given a set of initial states  $\mathcal{x}_0\subseteq \mathcal{x}$ , a set of unsafe states  $\mathcal{x}_u\subseteq \mathcal{x}$ , and a set of goal states  $\mathcal{x}_g\subseteq \mathcal{x}$ , if there exist a barrier function  $b(\pmb {x})$  as in definition 3.1 and a lyapunov-like function  $v(\pmb {x})$  as in definition 3.2, then the policy  $\pmb {u} = \pmb {u}(\pmb {x})$  is both safe with respect to  $\mathcal{x}_u$  and goal-reaching with respect to  $\mathcal{x}_g$ .

# 4 learning neural certificates for safe and goal-reaching policies

as stated in theorem 2, obtaining the certificate functions, i.e., the barrier function  $b(\pmb{x})$  in definition 3.1 and lyapunov-like function  $v(\pmb{x})$  in definition 3.2, is the key step towards achieving a safe and goal-achieving policy. in this section, we resort to learning techniques and (deep) neural networks to find the policy together with learning the certificate functions. note that to keep notation simply, below we write  $\pmb{u}$  in  $\dot{\pmb{x}} = \pmb{f}_{\pmb{u}}(\pmb{x})$  as the parameter of a neural policy  $\pmb{u} = \pmb{u}(\pmb{x})$ .

# 4.1 construction of neural certificate functions

neural barrier functions. we construct the unknown barrier function as a multi-layer neural networks denoted as  $b_{\theta}(x)$ , where the input is the system state and the output is a scalar value;  $\theta$  denotes the parameter of the neural barrier function network; and we use tanh activation function in all layers to ensure the barrier function is differentiable with respect to its inputs. in order to successfully find a valid barrier function that satisfies the three conditions (4) in definition 3.1, we propose to minimize the following barrier certificate loss

$$
\begin{array}{l} \operatorname {l o s s} _ {b} (\boldsymbol {\theta}, \boldsymbol {u}) = \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \mathcal {x} _ {0}} b _ {\boldsymbol {\theta}} (\boldsymbol {x})\right) + \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \mathcal {x} _ {u}} (- b _ {\boldsymbol {\theta}} (\boldsymbol {x})) + \epsilon\right) \\ + \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \mathcal {x}} \nabla b _ {\boldsymbol {\theta}} (\boldsymbol {x}) \boldsymbol {f} _ {\boldsymbol {u}} (\boldsymbol {x}) + b _ {\boldsymbol {\theta}} (\boldsymbol {x})\right), \tag {6} \\ \end{array}
$$

where  $\pmb{u}$  is the parameter for a neural policy. here the first term on rhs of (6) is used to penalize the violation of (4a) in the barrier definition; the second term is to penalize the violation of (4b), where we use a small pre-defined  $\epsilon > 0$  to guarantee the strict inequality in (4b) holds; and the third term is to penalize the violation of (4c), for which we consider the extended class- $\mathcal{k}$  function  $\beta(\cdot)$  is  $x = \beta(x)$ . it is clear that a minimal zero-loss value of the above barrier-certificate loss function will indicate a valid barrier function  $b_{\theta}(\pmb{x})$ , which satisfies all conditions (4), and the learned policy  $\pmb{u}$  thus is safe.

one difficulty of minimizing the above barrier-certificate loss is that it contains three inner optimization problems for the neural barrier network, which might be computationally intractable for large-dimensional or deep networks. in implementation, we thus use the following empirical barrier certificate risk to approximate the above loss function:

$$
\begin{array}{l} l _ {b} (\boldsymbol {\theta}, \boldsymbol {u}) = \operatorname {r e l u} \left(\frac {1}{n _ {0}} \sum_ {i = 1} ^ {n _ {0}} b _ {\boldsymbol {\theta}} \left(\boldsymbol {x} _ {0} ^ {i}\right)\right) + \operatorname {r e l u} \left(\frac {1}{n _ {u}} \sum_ {i = 1} ^ {n _ {u}} b _ {\boldsymbol {\theta}} \left(\boldsymbol {x} _ {u} ^ {i}\right)\right), \tag {7} \\ + \operatorname {r e l u} \left(\frac {1}{n} \sum_ {i = 1} ^ {n} \left(\nabla b _ {\boldsymbol {\theta}} (\boldsymbol {x} ^ {i}) \boldsymbol {f} _ {\boldsymbol {u}} (\boldsymbol {x} ^ {i}) + b _ {\boldsymbol {\theta}} (\boldsymbol {x} ^ {i})\right)\right). \\ \end{array}
$$

where  $\{\pmb{x}_0^i\}_{i = 1}^{n_0},\{\pmb{x}_u^i\}_{i = 1}^{n_u}$ , and  $\{\pmb{x}^i\}_{i = 1}^n$  are the  $n_{0}$  samples of states sampled from the initial set  $\mathcal{x}_0$ ,  $n_{u}$  samples of states from  $\mathcal{x}_u$ , and  $n$  samples of states from the entire state domain  $\mathcal{x}$ , respectively.

the above relaxation, however, means that the minimal barrier-certicate risk (7) may not always guarantee the minimal (zero) loss of the barrier-certicate loss (6). thus, we need to have a verification step for the obtained barrier function  $b_{\theta}(\pmb{x})$  and policy  $\pmb{u}$ , which will be discussed later.

neural lyapunov-like functions. we construct the neural lyapunov-like function  $v_{\omega}(\pmb{x})$ , where its input is the state and output is a scalar value;  $\omega$  is the neural network parameter; and we use tanh activation in all layers to ensure  $v_{\omega}(\pmb{x})$  is differentiable with respect to its inputs. to satisfy the two conditions (5) of the lyapunov-like function, we propose the following lyapunov-like certificate loss:

$$
\begin{array}{l} \operatorname {l o s s} _ {v} (\boldsymbol {\omega}, \boldsymbol {u}) = \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \bar {\mathcal {x}} _ {g}} v _ {\boldsymbol {\omega}} (\boldsymbol {x})\right) + \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \mathcal {x} \backslash \bar {\mathcal {x}} _ {g}} (- v _ {\boldsymbol {\omega}} (\boldsymbol {x}))\right) \tag {8} \\ + \operatorname {r e l u} \left(\sup  _ {\boldsymbol {x} \in \mathcal {x}} \nabla v _ {\boldsymbol {\omega}} (\boldsymbol {x}) \boldsymbol {f} _ {\boldsymbol {u}} (\boldsymbol {x}) + v _ {\boldsymbol {\omega}} (\boldsymbol {x})\right), \\ \end{array}
$$

where  $\bar{\mathcal{x}}_g$  is any non-empty subset of the goal set  $\mathcal{x}_g$  (recall the set conditions in (5a) in definition 3.2), namely,  $\bar{\mathcal{x}}_g \neq \emptyset$  and  $\bar{\mathcal{x}}_g \subseteq \mathcal{x}_g$ , which can be flexibly chosen. the first two terms on rhs of (8) are to penalize the violation of condition (5a) in definition 3.2, and the third term is to penalize the violation of condition (5b), where we consider the extended class- $\mathcal{k}$  function  $\beta(\cdot)$  is  $x = \beta(x)$ .

it is clear that the minimal zero-loss value of (8) indicates a valid lyapunov-like function  $v_{\omega}(\pmb{x})$  satisfying all conditions in (5) and a goal-reaching policy  $\pmb{u}$ .

in practice, due to the complexity of directly minimizing the above lyapunov-like certificate loss (8), we choose its simple relaxation described as below. first, we construct  $v_{\omega}(\pmb{x})$  as

$$
v _ {\omega} (\boldsymbol {x}) = \phi_ {\omega} (\boldsymbol {x}) ^ {\prime} \phi_ {\omega} (\boldsymbol {x}), \tag {9}
$$

where  $\phi_{\omega}(\pmb {x}):\mathbb{r}^n\to \mathbb{r}^o$  can be a multiple neural layer. one property of this construction is that  $v_{\omega}(\pmb {x})\geq 0$  holds for all  $\pmb {x}\in \mathcal{x}$ . second, we define the empirical lyapunov-like certificate risk:

$$
l _ {v} (\boldsymbol {\theta}, \boldsymbol {u}) = \operatorname {r e l u} \left(\frac {1}{n _ {g}} \sum_ {i = 1} ^ {n _ {g}} v _ {\boldsymbol {\omega}} \left(\boldsymbol {x} _ {g} ^ {i}\right)\right) + \operatorname {r e l u} \left(\frac {1}{n} \sum_ {i = 1} ^ {n} \nabla v _ {\boldsymbol {\omega}} \left(\boldsymbol {x} ^ {i}\right) \boldsymbol {f} _ {\boldsymbol {u}} \left(\boldsymbol {x} ^ {i}\right) + v _ {\boldsymbol {\omega}} \left(\boldsymbol {x} ^ {i}\right)\right), \tag {10}
$$

where  $\{\pmb{x}_g^i\}_{i=1}^{n_g}$  and  $\{\pmb{x}^i\}_{i=1}^n$  are  $n_g$  samples of states sampled from the chosen goal subset  $\bar{\mathcal{x}}_g$ , and  $n$  samples of states from the entire domain  $\mathcal{x}$ , respectively. corresponding to the original (8), the rhs second term of (8) is removed because now the parameterized lyapunov-like function  $v_{\omega}(\pmb{x})$  in (9) is non-negative. again, the minimum of the above lyapunov-like certificate risk may not guarantee that the two conditions (5) of the lyapunov-like function are strictly satisfied. thus, we must verify the learned neural lyapunov-like function, as discussed in the next subsection.

# 4.2 joint learning of neural policies and neural certificates

as we have defined the barrier certificate risk  $l_{b}(\pmb{\theta})$  in (7) and the lyapunov-like certificate risk  $l_{v}(\omega)$  in (10), we can now join them together to define the total certificate risk below as our optimization objective:

$$
\min  _ {\boldsymbol {\theta}, \boldsymbol {\omega}, \boldsymbol {u}} l (\boldsymbol {\omega}, \boldsymbol {\theta}, \boldsymbol {u}) = \min  _ {\boldsymbol {\theta}, \boldsymbol {\omega}, \boldsymbol {u}} \left(l _ {b} (\boldsymbol {\theta}, \boldsymbol {u}) + l _ {v} (\boldsymbol {\omega}, \boldsymbol {u})\right), \tag {11}
$$

where  $\pmb{u}$  denotes the parameter of a neural network policy. optimizing the above total certificate risk  $l(\pmb{\omega},\pmb{\theta},\pmb{u})$  is a joint training of a policy neural network and two certificate neural networks (the barrier neural network and lyapunov-like neural network). we note that the total certificate risk  $l(\pmb{\omega},\pmb{\theta},\pmb{u})$  is positive semi-definite, and any  $(\pmb{\theta},\pmb{\omega},\pmb{u})$  corresponding to true certificate functions and policy satisfy  $l(\pmb{\theta},\pmb{\omega},\pmb{u}) = 0$ . thus the true certificate functions define a global minimizer for  $l(\pmb{\omega},\pmb{\theta},\pmb{u})$ .

verification of learned neural certificates. since  $l_{b}(\pmb{\theta}, \pmb{u})$  and  $l_{v}(\pmb{\omega}, \pmb{u})$  are relaxations of the barrier certificate loss (6) and lyapunov-like certificate loss (8), respectively, we cannot immediately say that the learned neural barrier and lyapunov-like certificates, which are the minimizer of (11), are valid in a sense of satisfying definition 3.1 and definition 3.2, respectively. thus, we must perform a verification step. to do so, we can employ multiple techniques, such as smt algorithms used in [7] and the lipschitz method used in [8]. in our case, we use a simple verification method similar to [8]. specifically, for example, to verify a scalar function  $h(\pmb{x}) < 0$  for  $\pmb{x} \in \mathcal{d}$ , it is sufficient to check the tightened condition  $h(\pmb{x}) < -l_h\tau = -\epsilon_1$  at finite set of points that can cover  $\mathcal{d}$ . here  $l_{h} > 0$  is the lipschiz constant of  $h(\pmb{x})$  and  $\tau > 0$  is a measure of how densely the points are located over  $\mathcal{d}$  [25]. in our experiments, we use a discretization of  $\mathcal{d}$  (possible adaptive discretization will yield better scaling to higher-dimensional state space [8]). to verify the first condition (5a) of the lyapunov-like function, since  $v_{\omega}(\pmb{x})$  is constructed to be non-negative in (9), we only verify if  $\min_{i=1,2,\dots} v_{\omega}(\pmb{x}_g^i) \leq \epsilon_2$ , where  $\epsilon_2 > 0$  is a small constant parameter that bounds the tolerable numerical error, and  $\pmb{x}_g^i$  are the points in the discretization of  $\bar{\mathcal{x}}_g$ . in our experiments, we set  $\epsilon_1 = \epsilon_2$ .

# 6 conclusions

this paper proposes a method for learning provably safe and goal-reaching policies. the key to achieve so is to learn the policy jointly with learning two additional certificate functions: one is the barrier function, and the other is the lyapunov-like function. we demonstrate the efficacy of the approach using different systems. we envision that this method provides a paradigm towards developing safe and goal-oriented learning techniques. we also envision the benefits of the method to the control field, where we show that by taking advantage of learning techniques, general barrier and lyapunov functions can be found using (deep) neural networks.

# broader impact

we envision that the results of this work could potentially benefit the learning community towards developing safe and goal-oriented learning algorithms. for example, in developing reinforcement learning algorithms, results of this work can be incorporated into the reinforcement learning framework to guarantee that the policy search is constrained within the set of safe policies. for deep learning research, for examples, learning (deep) neural networks, neural ordinary differential equations, or equilibrium models, use of the results of this work can guarantee that the learned model will provably converge towards a goal set. more importantly, inspired by the theoretical and experimental results of this work, we may conclude a more general learning paradigm: by including different certificate functions, one is able to simultaneously guarantee different aspects of performance of the learned models. this may benefit development of more complex but controllable learning systems in future.

we also envision that this work could benefit to the control field, because we provide a general solution on how to find the barrier and lyapunov functions using (deep) neural networks.

the proposed methods in this work do not leverage any bias in data.

# a proofs

before presenting proofs for the theorems of this paper, we provide some preliminaries which will be used in deriving proofs. first, we present the definition of forward invariance of a set.

definition a.1 (forward invariance of a set). given a dynamical system  $\dot{\pmb{x}} = \pmb{f}(\pmb{x})$  with  $\pmb{f}:\mathcal{x}\rightarrow \mathcal{x}\subseteq \mathbb{r}^n$ , we say a set  $\mathcal{s}\subseteq \mathcal{x}$  is forward invariant if for every  $\pmb {x}(0)\in \mathcal{s}$ , any state along the system trajectory  $\pmb {x}(t)$  starting from  $\pmb {x}(0)$  have  $\pmb {x}(t)\in s$  for all  $t\in \mathbb{r}_0^+$ .

second, we provide the nagumo's theorem [16, 26, 27] which establishes a sufficient and necessary condition to verify the invariance of a sub-level set of a continuously differentiable function.

theorem 3 (nagumo's theorem [16, 26, 27]). consider a dynamical system  $\dot{\pmb{x}} = \pmb{f}(\pmb{x})$  with  $\pmb{f}:\mathcal{x}\rightarrow \mathcal{x}\subseteq \mathbb{r}^n$  and a continuously differentiable scalar function  $h(\pmb {x}):x\to \mathbb{r}$ . define the zero sub-level set of  $h(\pmb {x})$  as  $\mathcal{c} = \{\pmb {x}\in \mathcal{x}:h(\pmb {x})\leq 0\}$ . the following two conditions are equivalent:

1)  $\mathcal{c}$  is forward invariant in a sense of definition a.1;  
2)  $\nabla h(\pmb {x})\pmb {f}(\pmb {x})\leq 0$  if  $\pmb {x}\in \{\pmb {x}\in \mathcal{x},h(\pmb {x}) = 0\}$

the above nagumo's theorem states that  $\dot{h}(t) = \nabla h(\pmb{x})\pmb{f}(\pmb{x}) \leq 0$  on the boundary of the zero sub-level set  $\mathcal{c}$  is a necessary and sufficient for  $\mathcal{c}$  to be forward invariant. please refer to [16, 26, 27] for more detail and proofs of this claim.

# a.1 proof of lemma 3.1

assume that a barrier function  $b(\pmb{x})$  satisfying the three conditions in (4) can be found. take any trajectory  $\pmb{x}_u(t)$  in  $\mathcal{x}$  that starts at some  $\pmb{x}(0) \in \mathcal{x}_0$  and consider the evaluation of  $b(\pmb{x}_u(t))$  along the trajectory. the condition (4c) directly indicates the second condition in the nagumo's theorem 3 holds, which is equivalent to say that  $\{\pmb{x} \in \mathcal{x} : b(\pmb{x}) \leq 0\}$  is forward invariance according to the nagumo's theorem. thus, along the trajectory  $\pmb{x}_u(t)$ ,  $b(\pmb{x}_u(t)) \leq 0$  holds for all  $t \in \mathbb{r}_0^+$ . consequently, any such trajectory can never reach an unsafe state whose  $b(\pmb{x})$  is positive according to (4b). we conclude that the safety of the system is guaranteed.

# a.2 proof of theorem 1

the proof of theorem 1 consists of three steps.

first, we need to show that the following set

$$
\mathcal {a} = \left\{\boldsymbol {x} \in \mathcal {x}: v (\boldsymbol {x}) \leq 0 \right\} \tag {i.1}
$$

is closed and invariant. its closeness is straightforward, and the invariance can be proved by applying the nagumo's theorem 3. specifically, from the condition (5b), if  $\pmb{x} \in \{\pmb{x} \in \mathcal{x} : v(\pmb{x}) = 0\}$ , then  $\nabla v(\pmb{x}) \pmb{f}_{\pmb{u}}(\pmb{x}) \leq 0$ , which directly indicates the second condition in the nagumo's theorem 3 holds. thus, we can say that  $\mathcal{a}$  is invariant by applying the nagumo's theorem 3.

second, we need to define another lyapunov function

$$
v _ {\mathcal {a}} (\boldsymbol {x}) = \left\{ \begin{array}{l l} 0 & \text {i f} \boldsymbol {x} \in \mathcal {a} \\ v (\boldsymbol {x}) & \text {i f} \boldsymbol {x} \in \mathcal {x} \backslash \mathcal {a} \end{array} . \right. \tag {i.2}
$$

combining the definition of the lyapunov-like function in definition 3.2, it is easy to show the following properties of the lyapunov function in (i.2): (i)  $v_{\mathcal{a}}(\pmb{x}) = 0$  for all  $\pmb{x} \in \mathcal{a}$ ; (ii)  $v_{\mathcal{a}}(\pmb{x}) > 0$  for all  $\pmb{x} \in \mathcal{x} \backslash \mathcal{a}$  due to (i.1); and (iii) for all  $\pmb{x} \in \mathcal{x} \backslash \mathcal{a}$ , we have

$$
v _ {a} (\boldsymbol {x}) = v (\boldsymbol {x}) \leq - \beta (v (\boldsymbol {x})) = - \beta \left(v _ {a} (\boldsymbol {x})\right), \tag {i.3}
$$

which is a result of directly applying the condition (5b) in definition 3.2.

third, based on the results obtained in the first and second steps, and also from the fact that  $v_{\mathcal{a}}(\pmb{x})$  is continuous on its domain and continuously differentiable at every point  $\pmb{x} \in \mathcal{x} \backslash \mathcal{a}$ , we can directly

apply theorem 2.8 in [24] to show that  $\mathcal{a}$  is asymptotically stable; that is, there exists a  $\mathcal{kl}$ -function  $\gamma$  such that for any  $\pmb{x}(0)\in \mathcal{x}\backslash \mathcal{a}$ ,

$$
\left\| \boldsymbol {x} _ {\boldsymbol {u}} (t) \right\| _ {\mathcal {a}} \leq \gamma (\left\| \boldsymbol {x} (0) \right\| _ {\mathcal {a}}, t) \tag {i.4}
$$

holds for all  $t \in \mathbb{r}_0^+$ . also combining  $\mathcal{a} \subseteq \mathcal{x}_g$  in (5a) of definition 3.2, it follows that

$$
\left\| \boldsymbol {x} _ {\boldsymbol {u}} (t) \right\| _ {\mathcal {x} _ {g}} \leq \left\| \boldsymbol {x} _ {\boldsymbol {u}} (t) \right\| _ {\mathcal {a}} \leq \gamma (\left\| \boldsymbol {x} (0) \right\| _ {\mathcal {a}}, t) \tag {i.5}
$$

holds for all  $t \in \mathbb{r}_0^+$ . this directly indicates that the controlled system is goal-reaching by definition 2.2. thus, we conclude that the existence of the lyapunov-like function in definition 3.2 guarantees the goal-reaching of the controlled system.

with the constants set as  $g = 10, l = 1, m = 1, d = 0.1$ . we define the state variable to be  $\pmb{x} = [\alpha, \dot{\alpha}]'$ . define the state domain as  $\mathcal{x} = \{ \pmb{x} : \pmb{x}_{\mathrm{lb}} \leq \pmb{x} \leq \pmb{x}_{\mathrm{ub}} \}$  with  $\pmb{x}_{\mathrm{lb}} = [-\pi, -5]'$  and  $\pmb{x}_{\mathrm{ub}} = [\pi, 5]'$ , the unsafe state set  $\mathcal{x}_u = \{ \pmb{x} : 2.5 \leq \| \pmb{x} \|_2 \leq 3 \}$ , the goal state set  $\mathcal{x}_g = \{ \pmb{x} : \| \pmb{x} \|_2 = 0 \}$ , and the initial state set  $\mathcal{x}_0 = \{ \pmb{x} : \| \pmb{x} \|_2 \leq 2 \}$ .

we set the neural policy network to be one-layer linear function (without bias):  $u = kx$ . for the neural barrier function  $b_{\theta}(x)$ , we use a 2-16-16-1 fully connected network with tanh activation function. for the neural lyapunov-like function  $v_{\omega}(x)$ , we use a 2-16-16-1 fully connected network with tanh activation function, but the last layer is modified to be dot product operation. the learning rate is set as  $10^{-3}$ . note that in our experiments, we always choose 4-layer neural networks for certificate functions, and the number of nodes in layers is set as  $n - 8n - 8n - 1$  with  $n$  is the dimension of input layer (i.e., state dimension).

$$
u = \left[ - 0. 3 2 8 6, - 0. 5 9 5 0 \right] \boldsymbol {x}. \tag {i.7}
$$

with both the lyapunov-like and barrier certificates, the learned neural policy is

$$

$$

cartpole system. the equation of the motion for the cartpole system is

$$
\ddot {x} = \frac {u + m _ {p} \sin \theta \left(l \dot {\theta} ^ {2} - g \cos \theta\right)}{m _ {c} + m _ {p} (\sin \theta) ^ {2}}, \tag {i.9a}
$$

$$
\ddot {\theta} = \frac {u \cos \theta + m _ {p} l \dot {\theta} ^ {2} \cos \theta \sin \theta - (m _ {c} + m _ {p}) g * \sin \theta}{l \left(m _ {c} + m _ {p} (\sin \theta) ^ {2}\right)}, \tag {i.9b}
$$

with the constants set as  $m_c = 1, m_p = 1, g = 1, l = 1$ . the system state variable is defined as  $\boldsymbol{x} = [x, \theta, \dot{x}, \dot{\theta}]'$ , where  $x$  is the position of the cart and  $\theta$  is the angle between pole and upward direction. define the state space  $\mathcal{x} = \{\boldsymbol{x} : \boldsymbol{x}_{\mathrm{lb}} \leq \boldsymbol{x} \leq \boldsymbol{x}_{\mathrm{ub}}\}$  with  $\boldsymbol{x}_{\mathrm{lb}} = [-1.3, -1.3, -1.3, -1.3]^{\prime}$  and  $\boldsymbol{x}_{\mathrm{ub}} = [1.3, 1.3, 1.3, 1.3, 1.3]^{\prime}$ , the unsafe state set  $\mathcal{x}_u = \{\boldsymbol{x} : 0.9 \leq \| \boldsymbol{x} \|_2 \leq 1.3\}$ , the goal state set  $\mathcal{x}_g = \{\boldsymbol{x} : \| \boldsymbol{x} \|_2 = 0\}$ , and the initial state set  $\mathcal{x}_0 = \{\boldsymbol{x} : \| \boldsymbol{x} \|_2 \leq 0.8\}$ .

we set the neural policy network to be one-layer linear function (without bias):  $u = kx$ . for the neural barrier function  $b_{\theta}(x)$ , we use a 4-32-32-1 fully connected network with tanh activation function. for the neural lyapunov-like function  $v_{\omega}(x)$ , we use a 4-32-32-1 fully connected network with tanh activation function, but the last layer is modified to be dot product operation. the learning rate is set as  $10^{-3}$ .

$$

vehicle path tracking system. the kinematic model of a wheeled vehicle tracking a reference path is given by [7]:

$$
\dot {s} = \frac {v \cos \theta_ {e})}{1 - d _ {e} \kappa (s)}, \tag {i.12a}
$$

$$
\dot {d} _ {e} = v \sin \left(\theta_ {e}\right), \tag {i.12b}
$$

$$
\dot {\theta} _ {e} = \frac {v \tan (u)}{l} - \frac {v \kappa (s) \cos \theta_ {e}}{1 - d _ {e} \kappa (s)}, \tag {i.12c}
$$

where  $\theta_e = \theta - \theta_r$  is the angle error between the vehicle orientation  $\theta$  and the reference path tangent angle  $\theta_r$ ;  $d_e$  is the distance error (see figure 4. (c) in [7]); and the constants are  $v = 6$  and  $l = 1$ . assuming that the reference path is a unit circle. define the state domain  $\mathcal{x} = \{\pmb{x} : \pmb{x}_{\mathrm{lb}} \leq \pmb{x} \leq \pmb{x}_{\mathrm{ub}}\}$  with  $\pmb{x}_{\mathrm{lb}} = [-0.8, -0.8]^{\prime}$  and  $\pmb{x}_{\mathrm{ub}} = [0.8, 0.8]^{\prime}$ , the unsafe state set  $\mathcal{x}_u = \{\pmb{x} : 0.6 \leq \| \pmb{x} \|_2 \leq 0.8\}$ , the initial state set  $\mathcal{x}_0 = \{\pmb{x} : \| \pmb{x} \|_2 \leq 0.5\}$ , and the goal state set  $\mathcal{x}_g = \{\pmb{x} : \| \pmb{x} - \pmb{x}_g \|_2 \leq 0.2\}$  with  $\pmb{x}_g = [-0.2, 0]^{\prime}$ .

we set the neural policy network to be one-layer linear function (without bias):  $u = kx$ . for the neural barrier function  $b_{\theta}(\pmb{x})$ , we use a 2-16-16-1 fully connected network with tanh activation function. for the neural lyapunov-like function  $v_{\omega}(\pmb{x})$ , we use a 2-16-16-1 fully connected network with tanh activation function, but the last layer is modified to be dot product operation. the learning rate is set as  $10^{-3}$ . with both the lyapunov-like and barrier certificates, the learned neural policy is

$$
u = \left[ - 0. 3 6 6 2, - 1. 7 8 0 2 \right] \boldsymbol {x}. \tag {i.13}
$$

uav control. the motion of equation for a uav flying in planar is given by:

$$
\ddot {x} = \frac {- \left(u _ {1} + u _ {2}\right) \sin \theta}{m}, \tag {i.14a}
$$

$$
\ddot {y} = \frac {\left(u _ {1} + u _ {2}\right) \cos \theta - m g}{m}, \tag {i.14b}
$$

$$
\ddot {\theta} = \frac {r \left(u _ {1} - u _ {2}\right)}{i}, \tag {i.14c}
$$

where the constants are set as  $m = 0.1, g = 0.1, i = 0.1, r = 0.1$ . we define the state variable as  $\pmb{x} = [x, y, \theta, \dot{x}, \dot{y}, \dot{\theta}]'$  and the control variable  $\pmb{u} = [u_1, u_2]'$ . define the state domain  $\mathcal{x} = \{\pmb{x} : \pmb{x}_{\mathrm{lb}} \leq \pmb{x} \leq \pmb{x}_{\mathrm{ub}}\}$  with  $\pmb{x}_{\mathrm{lb}} = [-1, -1, -1, -1]'$  and  $\pmb{x}_{\mathrm{ub}} = [1, 1, 1, 1]'$ , the unsafe state set  $\mathcal{x}_u = \{\pmb{x} : 0.9 \leq \| \pmb{x} \|_2 \leq 1\}$ , the initial state set  $\mathcal{x}_0 = \{\pmb{x} : \| \pmb{x} \|_2 \leq 0.5\}$ , and the goal state set  $\mathcal{x}_g = \{\pmb{x} : \| \pmb{x} \|_2 = 0\}$ .
