# סיווג משלחי יד מנתוני סקר

הגשה מאוחדת למטלת הקבלה לתפקיד מדען נתונים בכיר. נתוני המקור סינתטיים.

- [המחברת המלאה, כולל תוצאות הריצה](survey_complete.ipynb)
- [פתיחה ב-Google Colab](https://colab.research.google.com/github/shulruferor-sudo/Advance-Data-Science/blob/main/project_notebooks/survey/survey_complete.ipynb)
- [מצגת בת 10 שקפים](survey_presentation.pptx)
- [המצגת כ-PDF](survey_presentation.pdf)
- [טבלאות התוצאות והמטריצות](survey_results/)

כדי להריץ: פותחים את המחברת ומפעילים Runtime → Run all במעבד CPU. אם המאגר פרטי, אפשר להוריד את המחברת ולהעלות אותה ל-Colab. קובץ ה-Excel המקורי כלול במחברת עם בדיקת SHA-256. אין צורך ב-SSH, בחיבור ל-Drive או בהעלאת קובץ נתונים נפרד.

המחברת כוללת טיפול בכל 18 השדות, שתי דרכי הכנה, חיפוש מלא עם GridSearchCV, עשרה קפלי אימון המפרידים קבוצות תיאור, השוואת אחת-עשרה אפשרויות סיווג וקו בסיס. כל פרמטר מסווג מכוונן כולל את ברירת המחדל ושתי חלופות מנומקות. הצבעה רכה והצבעה קשה כוללות כל אחת חמישה מודלים חדשים, עם כוונון נפרד בתוך CV. כל המאפיינים הנלמדים מותאמים בתוך האימון.


הבדיקה המקומית, גרסאות הספריות וזמן הריצה מתועדים ב-[run_manifest.json](survey_results/run_manifest.json). לא בוצעה הרצה בסשן Google Colab בפועל. הציונים מודדים התאמה לסימול הסינתטי ואינם התחייבות לאיכות תפעולית.
